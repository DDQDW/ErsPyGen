# PyDocx

**PyDocx** — кроссплатформенное приложение для **Android (arm64-v8a)** и **Windows**, созданное на базе Python и Flet. Позволяет выполнять собственные Python-скрипты и верстать готовые документы (`.docx`, `.pdf`, `.pptx`, `.xlsx`, `.md`, `.html`, `.txt`) прямо на телефоне или компьютере.

## Возможности (RU)

### 1. Свой скрипт (главный раздел)
- Выполнение Python-кода прямо в приложении с выводом логов и `print()` в реальном времени.
- Загрузка кода из файлов форматов `.py`, `.txt`, `.md`, `.json`, `.csv`, `.yaml`, `.yml`, `.js`, `.log` (для `.md` поддерживается автоматическое извлечение кода из блоков ```` ```python ... ``` ````).
- Встроенные функции для генерации документов: `create_docx`, `create_pptx`, `create_xlsx`, `create_pdf`, `create_txt`, `create_md`, `create_html`, `create_from_text`, `parse_layout`, `save_file`.
- Кнопки **`Сохранить <файл> в...`** для экспорта результата в любую папку через системный проводник.

### 2. Верстка из файла
- Преобразование текстовых файлов и разметки (Markdown, JSON, CSV, `TITLE:` / `TABLE:`, списки, таблицы) в документы **Word (`.docx`)**, **PDF (`.pdf`)**, **PowerPoint (`.pptx`)**, **Excel (`.xlsx`)**, **Markdown (`.md`)**, **HTML (`.html`)** и **Текст (`.txt`)**.
