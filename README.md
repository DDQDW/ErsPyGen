# PyDocx

**PyDocx** — кроссплатформенное приложение для **Android (`arm64-v8a`)** и **Windows**, созданное на Python и Flet. Позволяет выполнять собственные Python-скрипты и верстать готовые документы (`.docx`, `.pdf`, `.pptx`, `.xlsx`, `.md`, `.html`, `.txt`) прямо на телефоне или ПК.


---

## 🇷🇺 Описание и возможности

### 1. Свой скрипт (главный раздел)
- Выполнение Python-кода с выводом лога и `print()` в реальном времени.
- Загрузка кода из файлов `.py`, `.txt`, `.md`, `.json`, `.csv`, `.yaml`, `.yml`, `.js`, `.log` (в `.md` автоматически распознаются блоки кода ```` ```python ... ``` ````).
- Встроенные помощники: `create_docx`, `create_pptx`, `create_xlsx`, `create_pdf`, `create_txt`, `create_md`, `create_html`, `create_from_text`, `parse_layout`, `save_file`.
- Автоматическое отслеживание новых файлов, созданных скриптом (например, через `python-docx`), и кнопки **`Сохранить <файл> в...`** для экспорта через системный проводник.

### 2. Верстка из файла
- Преобразование текстовой разметки (Markdown, JSON, CSV, директивы `TITLE:` / `TABLE:`, списки, таблицы) в документы **Word (`.docx`)**, **PDF (`.pdf`)** с поддержкой кириллицы (`DejaVuSans.ttf`), **PowerPoint (`.pptx`)**, **Excel (`.xlsx`)**, **Markdown (`.md`)**, **HTML (`.html`)** и **Текст (`.txt`)**.
- Возможность запустить загруженный файл напрямую как скрипт.

### 3. Настройки
- Папка сохранения по умолчанию — **`Documents/PyDocx`** (настраивается вручную или через проводник).
- Сохранение результата **рядом с исходным файлом**, если открыт файл с диска (при ручном вводе или вставке используется папка по умолчанию).
- Запрос разрешения на запись во внешнее хранилище на Android.

### Стек и адаптивный интерфейс
- **Android (`arm64-v8a`)**: компактные вкладки `TabBar`, поддержка Storage Access Framework (`Сохранить ... в...`).
- **Windows**: боковая панель `NavigationRail`, шрифты Segoe UI / Consolas и двухколоночная рабочая область (редактор + панель логов и экспорта).
- **Сборка**: автоматическая сборка APK и Windows-версии через GitHub Actions (`.github/workflows/build.yml`).
